# joshspeakman.github.io

The source for [joshspeakman.github.io](https://joshspeakman.github.io), my personal site: the apps, websites and games I build, and the classic PC games I've rebuilt to run natively on modern machines.

It's a single static page with no build step. Every push to `master` deploys it through GitHub Actions, and the version numbers, release dates and stars on it come straight from GitHub.

Game names and artwork belong to their publishers.
